# FITBUDDY AI ## Project Report ### 1. Introduction FitBuddy AI is a fitness plan generator application developed using Python and FastAPI. It helps users generate workout plans based on their fitness goals and fitness level. The application also provides nutrition tips and a feedback option. ### 2. Objectives - To provide a simple fitness planning application. - To generate workout plans based on user requirements. - To provide general nutrition tips. - To collect user feedback. ### 3. Technologies Used - Python - FastAPI - HTML - CSS - JavaScript - VS Code ### 4. Features - Workout Plan Generator - Nutrition Tips - Fitness Tips - User Feedback - FastAPI REST APIs - User-friendly Web Interface ### 5. Conclusion FitBuddy AI provides a simple and user-friendly platform for generating workout plans, accessing nutrition tips, and submitting feedback. The project demonstrates the practical use of Python, FastAPI, HTML, CSS, and JavaScript in developing a fitness application. ## Future Enhancements - Add AI-based personalized fitness recommendations. - Add progress tracking for users. - Add more workout and nutrition plans. - Add user login and profile management. - Add mobile application support. ### 7. System Requirements #### Hardware Requirements - Computer or Laptop - Minimum 4 GB RAM - Minimum 10 GB free storage - Internet connection #### Software Requirements - Windows 10/11 - Python - FastAPI - Uvicorn - Visual Studio Code - Web Browser ### 8. System Architecture The FitBuddy AI application follows a simple client-server architecture. 1. User enters fitness details through the web interface. 2. The frontend sends the user data to the FastAPI backend. 3. FastAPI processes the request. 4. The backend generates the required workout plan or provides nutrition and fitness information. 5. The result is sent back to the frontend. 6. The user can also submit feedback through the application. ### 9. API Endpoints | Method | Endpoint | Purpose | |---|---|---| | GET | /health | Checks the application health | | POST | /workout | Generates a workout plan | | GET | /tip | Provides a fitness tip | | GET | /nutrition | Provides nutrition tips | | POST | /feedback | Submits user feedback | | GET | / | Displays the FitBuddy AI home page | ### 10. Project Workflow 1. User opens the FitBuddy AI web application. 2. User selects a fitness goal and fitness level. 3. User enters the number of workout days per week. 4. The frontend sends the details to the FastAPI backend. 5. The backend processes the request and generates the workout plan. 6. Nutrition tips can be viewed through the application. 7. Users can submit their feedback. 8. The application displays the results to the user. ### 11. Testing The FitBuddy AI application was tested using the following features: - Health API was tested using GET /health. - Workout generation was tested using POST /workout. - Fitness tip was tested using GET /tip. - Nutrition tips were tested using GET /nutrition. - Feedback submission was tested using POST /feedback. - The web interface was tested through the browser. All the main features were successfully tested and working as expected. ### 12.
